# 问题排查

| 现象 | 检查项 |
|---|---|
| 找不到耳机 | 在系统蓝牙设置连接耳机，并授权附近设备。列表只显示已连接的耳机音频设备。 |
| 蓝牙已连接但无法控制 | 控制能力取决于型号、固件和系统是否允许打开协议通道。系统能提供电量时仍可查看电量。 |
| 自动连接变成带按钮的通知 | 系统限制了后台启动。点按「连接」，或在设置选择「关联耳机以允许后台自动连接」。 |
| 移动数据规则触发，Wi-Fi 不触发 | 授予精确位置权限、打开定位，用「使用当前 Wi-Fi」获取系统报告的名称，并确认控制会话仍在运行。 |
| 有通知但状态栏没有胶囊 | 检查通知和实况通知权限。是否显示胶囊取决于手机固件。 |
| Android 报告签名冲突 | 使用同一密钥签名的新版。由调试包迁移到正式签名时，可能需卸载旧版，卸载会清除本地设置。 |
