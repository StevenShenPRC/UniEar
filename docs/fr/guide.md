# Premiers pas

Téléchargez l’APK signé depuis les versions GitHub. Android 8.0 ou ultérieur est requis. Associez puis connectez le casque dans les réglages Bluetooth. Dans UniEar, recherchez les casques connectés, sélectionnez le vôtre et touchez **Connecter**.

Activez séparément la notification, la tuile de réglages rapides, le widget ou les commandes flottantes. Touchez la tuile pour changer de mode et maintenez-la pour ouvrir UniEar.

La connexion automatique effectue jusqu’à trois tentatives. Sans elle, l’offre de connexion dure environ 30 secondes. Android 16 peut afficher une mise à jour en direct. Les règles réseau associent un SSID Wi-Fi ou les données mobiles à un mode. Lisez le nom du réseau avec la localisation précise activée.
