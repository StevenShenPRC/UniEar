# 快速开始

1. 从 [Releases](https://github.com/StevenShenPRC/UniEar/releases) 下载正式签名的 APK。系统需为 Android 8.0 或更新版本。
2. 先在系统蓝牙设置配对并连接耳机，再在 UniEar 点按「查找已连接耳机」，选中设备后点按「连接」，建立控制通道。
3. 控制通道就绪后，可切换降噪模式或调整当前型号支持的设置。

## 快捷控制

通知中心菜单、控制中心磁贴、桌面小组件和悬浮胶囊在设置中有独立开关。短按磁贴轮换支持的模式，长按打开 UniEar。展开会话通知可查看型号、电量和连接信息。

## 自动连接与网络规则

在「设置 → 耳机连接」开启自动连接，或关闭自动连接并开启连接实况。每次蓝牙连接最多自动尝试三次，连接提示保留约 30 秒，可选「连接」或「忽略」。Android 16 可按系统设置将通知提升为 Live Update。

在「设置 → 网络自动化」为各 Wi-Fi SSID 或移动数据配置模式。读取 Wi-Fi 名称需要精确位置权限和系统定位。规则在 UniEar 控制会话期间生效。
