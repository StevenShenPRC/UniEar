# Dépannage

- Aucun casque trouvé : connectez-le dans les réglages Bluetooth et autorisez les appareils à proximité.
- Aucune commande : le modèle, le micrologiciel ou Android peut limiter le canal. Associez le casque pour autoriser la connexion en arrière-plan.
- Règle Wi-Fi inactive : autorisez la localisation précise, activez la localisation et vérifiez que le canal de commande est actif.
- Pas de capsule : vérifiez les autorisations de notification. Le micrologiciel décide de l’affichage.
- Signature incompatible : utilisez une version signée avec la même clé. Désinstaller une version de débogage efface ses réglages.
