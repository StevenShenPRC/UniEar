# Primeros pasos

Descarga el APK firmado desde las versiones de GitHub. Se requiere Android 8.0 o posterior. Vincula y conecta los auriculares en los ajustes Bluetooth. En UniEar, busca los auriculares conectados, selecciona los tuyos y pulsa **Conectar**.

Activa por separado la notificación, el botón de ajustes rápidos, el widget o los controles flotantes. Pulsa el botón para cambiar de modo y mantenlo pulsado para abrir UniEar.

La conexión automática realiza hasta tres intentos. Sin ella, el aviso de conexión dura unos 30 segundos. Android 16 puede mostrar una actualización en directo. Las reglas de red asocian un SSID Wi-Fi o los datos móviles a un modo. Para leer el nombre de Wi-Fi, activa la ubicación y concede acceso preciso.
