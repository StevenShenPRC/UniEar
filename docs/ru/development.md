# Разработка и выпуски

Установите Git, JDK 17, Python 3.10 или новее, Android SDK 36 и Build Tools 36.0.0. В Windows используйте `gradlew.bat`.

```sh
python scripts/hyperears.py checkout
sh ./gradlew :core:test :desktop:compileKotlin :android:assembleDebug
```

Увеличьте `versionCode` и обновите `versionName`. Настройте секреты `UNIEAR_KEYSTORE_BASE64` и `UNIEAR_KEYSTORE_PASSWORD`, затем отправьте соответствующий тег `vX.Y.Z`. Процесс проверит подпись и добавит APK и контрольную сумму SHA-256 в выпуск GitHub.

В каталоге `docs` выполните `npm ci`, затем `npm run dev` или `npm run build`. Статический сайт создаётся в `.vitepress/dist`.

## Выпуск по префиксу коммита

Отправьте в `main` коммит с первой строкой `release-v1.2.3:` для стабильного выпуска или `beta-v1.2.3:` для предварительного. Теги будут `v1.2.3` и `beta-v1.2.3`. После префикса допустим конец строки, пробел или двоеточие.

Числовая версия должна совпадать с `versionName`; увеличьте `versionCode`. После сборки, подписи и проверки запуска APK и его SHA-256 добавляются к GitHub Release. Бета помечается Prerelease и не становится Latest. Проверяется только заголовок последнего отправленного коммита. При squash или merge укажите префикс в заголовке итогового коммита.

Теги `vX.Y.Z` и `beta-vX.Y.Z` также поддерживаются. Для каждой новой беты используйте новый номер. Повторный запуск сохраняет опубликованные файлы. Тег на другом коммите вызывает ошибку. Ручной запуск проверяет и собирает без публикации.
