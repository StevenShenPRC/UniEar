# Начало работы

Скачайте подписанный APK из выпусков GitHub. Требуется Android 8.0 или новее. Выполните сопряжение и подключение в настройках Bluetooth. В UniEar найдите подключённые наушники, выберите нужные и нажмите **Подключить**.

Отдельно включайте управление из уведомления, плитку, виджет или плавающие элементы. Нажатие на плитку меняет режим, удержание открывает UniEar.

Автоподключение выполняет до трёх попыток. Без него предложение подключения доступно около 30 секунд. Android 16 может показывать обновление в реальном времени. Правила сети связывают режим с SSID Wi-Fi или мобильными данными. Для чтения имени Wi-Fi нужна точная геолокация.
